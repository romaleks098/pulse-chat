## 1. Главные правила и регламент внесения изменений

Каждый раз, когда в проект вносятся любые правки:
1. **Запрет на утечку секретов**: Никогда не писать в код, тесты, README, `render.yaml` или отчёты пароли, токены, секреты API и полные строки подключения.
2. **Проверка перед коммитом**:
   - `npm run check:secrets` — проверка отсутствия секретов в коде.
   - `npm run build` — сборка клиента и сервера без ошибок.
   - `npm test` — прохождение всех автотестов.
3. **Обязательная запись в `AI_README.md`**: зафиксировать версию, дату, суть обновления или фичи, список затронутых файлов и результаты тестов.
4. **Синхронизация деплоя**: после коммита пушить в обе ветки для Render: `git push origin main` и `git push origin main:master`.

## 2. Архитектура проекта и технологический стек

- **Фронтенд (`client/`)**:
  - React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons.
  - Менеджмент состояния: `ChatContext.tsx`, `ThemeContext.tsx`, `CallContext.tsx`.
  - Дизайн-токены: единая система CSS-переменных на `:root` (поверхности, текст, акцент, пузыри, радиусы, шрифты, тени, плотности).
  - UI-примитивы (`client/src/components/ui/`): `Avatar`, `Badge`, `ContextMenu`, `Modal`, `Tabs`, `Toast`, `Slider`, `ColorPicker`.
- **Бэкенд (`server/`)**:
  - Node.js, Express, TypeScript, Socket.io, Multer, `better-sqlite3` (локально) / `pg` (в облаке Render).
  - Эндпоинты: `/api/auth`, `/api/conversations`, `/api/messages`, `/api/health`, `/api/sync`.
  - Безопасность: PKCE OAuth 2.0 с хранением `state` в БД, постоянная по времени проверка `timingSafeEqual` для Telegram Webhook, безопасные cookies (`HttpOnly`, `Secure`, `SameSite=Lax`).
- **Мобильная и десктоп платформы**:
  - Capacitor Android SDK (`client/android`), PWA Manifest, Service Worker, Windows Desktop Launcher (`PulseChat-Desktop.bat` / `npm run desktop`).

## 4. Журнал всех обновлений и изменений

### Версия 1.7.0
**Дата:** 2026-10-24  
**Коммит:** `cff0ecb`  
**Категория:** Обновление / Telegram UI/UX / Этап 4  
**Суть обновления:**  
Комплексный перенос интерфейса мессенджера на стандарт Telegram с глубокой настройкой, плавной адаптивностью и поддержкой мобильных устройств.

**Что сделано:**
1. **Левая панель (Sidebar):**
   - Добавлен мышиный ресайз ширины сайдбара (диапазон 260–500px), ширина сохраняется в `localStorage` и применяется через CSS-переменную `--sidebar-width`.
   - В превью сообщений добавлены иконки типов: 📷 «Фото», 📎 «Файл», 🎤 «Голосовое».
   - Анимированный индикатор набора текста: живые точки и статус `[Имя] печатает…` акцентным цветом при наборе текста собеседником.
   - Поддержка черновиков в списке чатов: неактивные чаты с сохранённым черновиком подсвечиваются плашкой `Черновик: <текст>`.
   - Статусы доставки и прочтения для исходящих сообщений в списке: `Check` (доставлено) или `CheckCheck` (прочитано).
   - Контекстное меню чата по правому клику мыши и по долгому тапу (450 мс) на мобильных устройствах: «Закрепить/Открепить», «Без звука/Включить звук», «Прочитано», «Очистить историю», «Удалить чат».
   - Добавлен серверный эндпоинт `DELETE /api/conversations/:id` для удаления/выхода из диалога.
2. **Центральное окно чата (ChatArea):**
   - **Группировка сообщений подряд**: рассчитываются `isSameAuthorPrev` и `isSameAuthorNext` (сообщения от одного автора в пределах 5 минут). Внутренние углы пузырей сглаживаются до 4px, внешние сохраняют `--bubble-radius`.
   - **SVG-хвостики сообщений Telegram**: отрисовываются на нижнем краю последнего сообщения кластера (справа для исходящих, слева для входящих).
   - **Аватар автора**: выводится только внизу последнего сообщения кластера входящих; для предыдущих сообщений сохраняется ровный отступ.
   - **Имя автора в группах**: выводится только в шапке первого сообщения группы.
   - **Время и галочки внутри пузыря**: метка времени и `CheckCheck` аккуратно встроены справа внизу каждого пузыря.
   - **Плавающая кнопка «Вниз»**: появляется при отмотке вверх на >160px, отображает бейдж непрочитанных и плавно скроллит вниз.
   - **Контекстное меню сообщения**: в шапку меню встроена панель быстрых реакций-эмодзи (👍, ❤️, 🔥, 😂, 😮, 😢, 🙏, 👏), копирование, ответ, закрепление, редактирование и удаление.
3. **Поле ввода (Composer):**
   - Автовысота `textarea` до 6 строк (~168px).
   - Баннеры цитирования (Reply) и редактирования (Edit) над полем ввода с кнопкой отмены (Escape / крестик).
   - Стрелка вверх (`↑`) в пустом поле ввода открывает последнее собственное сообщение на редактирование.
   - **Черновики per-conversation**: черновик каждого чата сохраняется в `localStorage` по ключу `pulse_draft_${conversationId}`, автоматически восстанавливается при переключении между чатами и стирается при отправке.
   - Запись голосовых сообщений (компонент `VoiceRecorder`).
4. **Правая панель информации (RightInfoPanel):**
   - Выдвигается при клике на шапку чата.
   - Профиль собеседника / группы, статус «в сети», кликабельное копирование `@username`, описание/био.
   - 4 вкладки медиа-вложений на базе компонента `Tabs`: «Медиа» (сетка фото), «Файлы» (документы с размером), «Ссылки» (все найденные URL в переписке), «Голос» (голосовые сообщения).

**Затронутые файлы:**
- `client/src/components/ChatArea.tsx`
- `client/src/components/Sidebar.tsx`
- `client/src/components/RightInfoPanel.tsx`
- `client/src/components/ui/ContextMenu.tsx`
- `client/src/context/ChatContext.tsx`
- `client/src/services/api.ts`
- `server/src/routes/conversations.ts`

### Версия 1.5.0
**Дата:** 2026-10-23  
**Категория:** Исправление бага / Целостность данных  
**Суть обновления:**  
Автоматическое слияние дубликатов «Избранного» в БД без потери переписки и изоляция каналов от групп.

**Что сделано:**
- Реализована процедура `healAndConsolidateSavedMessages()` в `server/src/db.ts`: находит пользователей с несколькими чатами «Избранное», переносит все сообщения в канонический чат (`UPDATE messages SET conversation_id = <canonical_id> WHERE conversation_id = <dup_id>`) и удаляет дубликаты.
- В `client/src/components/Sidebar.tsx` фильтр групп строго ограничен: `c.type === 'group' && !c.isChannel`.

**Затронутые файлы:**
- `server/src/db.ts`
- `server/src/routes/conversations.ts`
- `client/src/components/Sidebar.tsx`

**Категория:** Безопасность / OAuth 2.0 PKCE / Webhooks  
**Суть обновления:**  
Надёжная и безопасная авторизация через Google, GitHub и Telegram.

**Что сделано:**
- Детальное логирование OAuth ошибок без утечки `client_secret` и одноразового `code`.

- Cookie с флагами `HttpOnly`, `Secure`, `SameSite=Lax`.

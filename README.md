# 💬 PulseChat — Мессенджер для ПК и Android

Современный кроссплатформенный мессенджер реального времени с поддержкой личных и групповых чатов, отправки файлов и картинок, эмодзи-реакций, статусов онлайна и PWA/Capacitor интеграцией для Android и ПК.

---

## 🖥️ Приложение для ПК (Windows)

Для запуска нативного десктопного приложения PulseChat на ПК:

1. **Быстрый запуск**: Дважды кликните по файлу **`PulseChat-Desktop.bat`** в корне проекта.
2. **Либо через терминал**:
   ```bash
   npm run desktop
   ```
Откроется полноценное отдельное Windows-окно с мессенджером, темной темой, поддержкой горячих клавиш и аппаратным ускорением звонков.

---

## 📱 Приложение для Android (APK)

Для Android доступно 3 способа:

1. **Скачать готовый `.apk` из GitHub Actions**:
   - Откройте вкладку [GitHub Actions в вашем репозитории](https://github.com/romaleks098/pulse-chat/actions).
   - Выберите последний запуск сборки **«Build Android APK & Windows App»**.
   - Внизу в блоке **Artifacts** скачайте готовый установочный файл **`PulseChat-Android-APK`** прямо на телефон.
2. **Установка как PWA (без сборки)**:
   - Откройте мессенджер в мобильном Chrome и нажмите в меню браузера **«Установить приложение»**.
3. **Локальная сборка в Android Studio**:
   ```bash
   npm run cap:android
   ```

## 🚀 Быстрый старт

### 1. Запуск в режиме разработки (ПК + Локальная сеть)

В корневой директории проекта выполните:

```bash
npm run dev
```

Эта команда автоматически запустит одновременно:
- **Бэкенд (Node.js + Express + Socket.io + SQLite)** на `http://0.0.0.0:3001`
- **Фронтенд (React + Vite + Tailwind CSS)** на `http://0.0.0.0:5173`

## 📱 Как открыть на Android и ПК

### Вариант 1: Быстрый вход по Wi-Fi (PWA)
1. Откройте мессенджер на ПК по адресу [http://localhost:5173](http://localhost:5173).
2. Нажмите иконку **телефона / QR-кода** в левом верхнем углу (или в шапке чата).
3. Наведите камеру смартфона на открывшийся QR-код (или введите отображаемый локальный IP, например `http://192.168.0.x:5173`).
4. В браузере смартфона (Chrome) нажмите на три точки и выберите **«Установить приложение»** / **«Добавить на главный экран»**.
5. На рабочем столе Android появится полноценная иконка PulseChat, открывающаяся без рамок браузера как нативное приложение.

### Вариант 2: Сборка нативного Android APK (Capacitor)
Проект уже содержит сконфигурированную платформу Capacitor Android (`client/android`):

```bash
# 1. Синхронизировать сборку веб-клиента в нативный Android проект:
npm run cap:sync

# 2. Открыть проект в Android Studio для сборки .apk:
npm run cap:android
```

## 🛠 Технологический стек

- **Бэкенд**:
  - Node.js & TypeScript (`tsx`)
  - Express.js (REST API)
  - Socket.io (двунаправленные вебсокеты)
  - SQLite (быстрая встроенная БД через `better-sqlite3` с режимом WAL)
  - Multer (загрузка фотографий и документов)
  - JWT + bcryptjs (безопасное хэширование паролей и авторизация)
- **Фронтенд**:
  - React 19 & TypeScript
  - Vite (мгновенная сборка)
  - Tailwind CSS (современный адаптивный дизайн)
  - Lucide Icons
  - Socket.io Client
  - QRCode.react (динамическая генерация QR для синхронизации с телефоном)
  - PWA Manifest & Service Worker
- **Мобильная платформа**:
  - Capacitor Android SDK (генерация нативного приложения для Android)

## ✨ Реализованный функционал

1. **Аудио- и видеозвонки (WebRTC P2P)**:
   - Кнопка **📞 Аудиозвонка** и **📹 Видеозвонка** прямо в шапке любого чата.
   - Прямой P2P-видео/аудио поток между устройствами (ПК ↔ Android) без нагрузки на сервер.
   - Экран входящего вызова с кнопками «Принять» и «Отклонить».
   - Режим «Картинка в картинке» (PiP) для собственной камеры и полноэкранное видео собеседника.
   - Таймер длительности разговора, быстрое отключение микрофона (Mute) и выключение камеры.
   - Бесплатные Google STUN-серверы для беспрепятственного соединения через мобильный интернет и Wi-Fi.
2. **Аутентификация & Профиль**:
   - Вход и регистрация через **Telegram**, **Google** и **GitHub**.
   - Классическая регистрация и вход по логину и паролю.
   - Выбор аватара из готовой галереи или кастомный URL.
   - Изменение отображаемого имени и текста статуса ("На связи", "В отпуске" и т.д.).
2. **Личные и групповые чаты**:
   - Мгновенный поиск любого пользователя по никнейму или имени.
   - Личные переписки (1-на-1) без дублирования диалогов.
   - Создание групповых каналов с выбором нескольких участников.
3. **Сообщения реального времени**:
   - Мгновенная доставка сообщений через WebSockets.
   - Индикатор набора текста ("Иван печатает...").
   - Индикатор онлайна собеседника (зеленая точка в реальном времени).
   - Ответы (reply) с красивым цитированием исходного сообщения.
   - Редактирование и удаление собственных сообщений.
   - Эмодзи-реакции (👍, ❤️, 🔥, 😂, 😮, 😢) с подсчетом голосов и подсказкой, кто отреагировал.
4. **Медиафайлы и документы**:
   - Прикрепление фото и файлов через скрепку (Drag & Drop / выбор файла).
   - Встроенный просмотрщик изображений (lightbox) с возможностью скачивания.
   - Отображение размера файла и типа документа.
5. **Адаптивность (Dual-mode)**:
   - На ПК: двухколоночный режим (список чатов слева, открытый диалог справа).
   - На Android: мобильный экран со списком чатов и кнопкой «Назад» при входе в диалог.
